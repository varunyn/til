# TIL

## Purpose
Varun Yadav's public collection of practical code notes, fixes, and things learned day to day. Visitors browse notes, explore topics, search articles, and read technical posts.

## Platform
Web, including mobile browsers. Next.js with static export. No runtime API routes; data is prepared at build time.

## Constraints
Preserve published article content, public links, search, theme switching, RSS, and accessible navigation. Support touch, keyboard, reduced motion, and light/dark themes. Avoid extra content reads when existing post data can supply the same information.

## Confirmed direction
The user approved solid neutral light/dark surfaces, restrained sans-serif typography, orange accents, a distinctive TIL wordmark, mobile bottom navigation, compact article rows, and topic filters. The user explicitly rejected paper backgrounds and notebook styling. Following review, they approved a quieter personal developer site: smaller headings, first-person introduction, sparse orange accents, compact title/topic spacing, and no decorative slogans. The user prefers orange topic labels paired with published dates in the compact metadata line.

## Audience
Inferred from the content: readers looking for practical technical notes. More specific audience positioning is undecided.
